## 🌟 Overview

Designed with clean typography, responsive layouts, and accessibility in mind, this portfolio highlights my background in full-stack web development, database management systems, systems programming, and mobile app creation.

---

## ✨ Key Features

* **Fully Responsive Design:** Optimized across desktop, tablet, and mobile breakpoints using custom CSS grid, flexbox, and media queries.
* **Accessibility Features:** Built with semantic HTML elements and accessible design considerations for screen readers.
* **Direct Project Showcase:** Sections highlighting game jam winning entries, full-stack desktop software, and mobile apps.
* **Resume & Direct Contact Links:** Quick download links for CV/Resume and integrated contact information.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling & Layout:** Custom CSS Variables, Flexbox, CSS Grid, Media Queries (`mediaqueries.css`)
* **Hosting & CI/CD:** Netlify (Continuous Deployment linked via GitHub)
